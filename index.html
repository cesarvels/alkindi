Alfabeto de trabajo

El sistema utiliza por defecto los caracteres ASCII imprimibles. También permite ampliar o sustituir el conjunto de caracteres utilizado para el cifrado y descifrado.

Cada carácter debe aparecer una sola vez. Puedes incluir letras, números, espacios, símbolos y otros caracteres Unicode.

Funcionamiento del sistema

César

Desplaza cada carácter del texto dentro del alfabeto definido por el sistema. Durante el proceso automático se prueban todas las rotaciones posibles.

Atbash

Sustituye cada carácter por su equivalente en posición inversa dentro del alfabeto.

Al-Kindi

El sistema compara las diferentes posibilidades mediante análisis estadístico y lingüístico para determinar cuál presenta mayor probabilidad de ser una oración válida en español.

ASCII

El sistema utiliza los valores numéricos de los caracteres como fundamento para realizar las operaciones de desplazamiento.
